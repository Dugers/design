# Графика

`night-sea.webp` — иллюстрация для первой версии, сгенерирована ImageGen по стилевому референсу аватарки. `night-sea.png` — исходный результат. WebP получен только конвертацией формата; содержание не менялось.

Промпт генерации:

> Use case: illustration-story. Create an original web illustration, using the attached reference ONLY as style guidance: simple hand-drawn digital storybook art, thick slightly wobbly dark brown outlines, flat muted colors, subtle crayon/pencil texture, gentle naive graphic drawing like the girl's avatar. This is a wide quiet night seascape, isolated on transparent background. In the lower center a tiny folded paper boat floats on a few softly curling waves, two thin looping pencil paths rise into the air and link a small dusty-pink five-pointed star high at the right and a thin cream crescent moon on the left. A few scattered tiny brown/cream dots, 3 small four-point star glints. Asymmetric balanced horizontal composition, mostly empty negative space in upper middle. Broad rolling ocean waves in warm charcoal taupe and muted brown, outlined with lighter dusty taupe, not blue. Paper boat muted warm parchment, pink star uses #d69bac. Website background will be #211b1d so make drawing visible against that dark field with muted cream/taupe outlines. No people, faces, hearts, flowers, buildings or text. Flat 2D charming handmade illustration, no realism, no 3D, no glows, no gradients, not elaborate, minimal. Transparent background. Landscape aspect ratio 3:2.

`paper-grain.png` — процедурная монохромная фактура, seed 41. `star.svg` и встроенные иконки — нарисованные SVG-контуры.

`fonts/comfortaa.otf` — локальный резервный и текстовый шрифт Comfortaa. Лицензия: `fonts/OFL.txt`. Caveat для рукописных заголовков подключен через Google Fonts; без интернета используется Comfortaa.
