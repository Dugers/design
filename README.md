# 22:18

Статический сайт независимой дизайн-студии, отдельная личная история и журнал ежедневных действий. Существующий стек HTML/CSS/JS сохранен.

## Запуск и сборка

```sh
npm run dev
npm run check
npm run build
```

Локально: `http://localhost:5173/`, `http://localhost:5173/story/` и `http://localhost:5173/todo/`. Страницу todo нужно открывать через сервер, поскольку она использует ES-модули. Сборка создает `dist/` без зависимости от npm-пакетов. `npm run check` проверяет синтаксис скриптов, логику журнала действий, собирает сайт и проверяет пути в контексте GitHub Pages `/design/`, SVG-якоря, переход через иллюстрацию и логику раскрытия старых записей.

GitHub Pages публикует содержимое `dist/` через существующий workflow после push в master:

- `https://dugers.github.io/design/` — студия 22:18.
- `https://dugers.github.io/design/story/` — прежняя история.
- `https://dugers.github.io/design/todo/` — личный журнал действий.

Новые изменения не отправлены в GitHub автоматически.

## Структура

- `index.html`, `studio.css`, `studio.js`: портфолио, фильтры, описания четырех проектов, услуги и скачивание брифа.
- `assets/studio/`: пять изображений проектов, favicon и промпты генерации.
- `story/index.html`: история с сохраненным оформлением и механикой. По последнему запросу добавлены личные даты 25.09, 04.10, 08.10, 09.10 и 10.10, обновлены маски будущих дат и добавлен многоуровневый намек на финал «Поправка к легенде».
- `style.css`, `script.js` и исходные ресурсы истории сохранены без изменений.
- `story/DESIGN.md`: прежняя система оформления истории; корневой `DESIGN.md` описывает новую главную.
- `scripts/build.mjs`: копирование публичных файлов без документации и тяжелого исходного PNG моря.
- `todo/`: отдельная страница журнала. Кнопки «Я закрыла дверь» и «Я выпила таблетку» записывают каждое выполнение; свои действия добавляются на сегодня или каждый день, галочкой или несколькими отметками. Прошлые дни доступны только для просмотра. Удаление архивирует действие и сохраняет сделанные отметки. Данные находятся в localStorage под ключом `katya-todo-v1`; при очистке данных браузера история удаляется и между устройствами не синхронизируется. Часовой пояс по умолчанию — Красноярск; настройки позволяют выбрать другой или время устройства. Смена пояса пересчитывает время и дни отметок, даты разовых задач остаются фиксированными. Открытая страница отслеживает смену дня и изменения в другой вкладке.

Иллюстрация «Фигуры в пространстве» ведет в `story/` обычной ссылкой, в том числе без JavaScript. Остальные работы открывают подробности; без JavaScript доступны сами изображения. Названия и изображения проектов представляют самостоятельные концепции, а не вымышленные клиентские заказы. Форма брифа сохраняет локальный TXT-файл и ничего не отправляет. Для приема заявок позже нужен настоящий контактный канал.

На главной шрифты локальные, лицензии в `assets/fonts/`. История сохраняет Google Fonts Caveat и локальный резервный Comfortaa. Новые WebP-изображения суммарно около 1,3 МБ; оригинальные личные фотографии в репозиторий не добавлены.

## Проверка

`npm run check` проверяет синтаксис, логику журнала, сборку, ссылки под `/design/` и сохранность старого содержимого. Для `/todo/` также выполнена проверка в Chromium: повторные отметки, защита от двойного нажатия, сохранение после перезагрузки, галочки и отмена, добавление и удаление действий с сохранением истории, смена часового пояса через границу дня и просмотр прошлых дней. Верстка просмотрена на desktop и экране 390 px, отсутствие горизонтального переполнения проверено также на 360 px; ошибок браузера не обнаружено.
