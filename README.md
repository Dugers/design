# 22:18

Статический сайт независимой дизайн-студии и отдельная личная история. Существующий стек HTML/CSS/JS сохранен.

## Запуск и сборка

```sh
npm run dev
npm run check
npm run build
```

Локально: `http://localhost:5173/` и `http://localhost:5173/story/`. Можно открыть оба index.html напрямую. Сборка создает `dist/` без зависимости от npm-пакетов. `npm run check` проверяет синтаксис обоих скриптов, собирает сайт и проверяет пути в контексте GitHub Pages `/design/`, SVG-якоря, переход через иллюстрацию и логику раскрытия старых записей.

GitHub Pages публикует содержимое `dist/` через существующий workflow после push в master:

- `https://dugers.github.io/design/` — студия 22:18.
- `https://dugers.github.io/design/story/` — прежняя история.

Новые изменения не отправлены в GitHub автоматически.

## Структура

- `index.html`, `studio.css`, `studio.js`: портфолио, фильтры, описания четырех проектов, услуги и скачивание брифа.
- `assets/studio/`: пять изображений проектов, favicon и промпты генерации.
- `story/index.html`: история с сохраненным оформлением и механикой. По последнему запросу добавлены личные даты 25.09, 04.10, 08.10, 09.10 и 10.10, обновлены маски будущих дат и добавлен многоуровневый намек на финал «Поправка к легенде».
- `style.css`, `script.js` и исходные ресурсы истории сохранены без изменений.
- `story/DESIGN.md`: прежняя система оформления истории; корневой `DESIGN.md` описывает новую главную.
- `scripts/build.mjs`: копирование публичных файлов без документации и тяжелого исходного PNG моря.

Иллюстрация «Фигуры в пространстве» ведет в `story/` обычной ссылкой, в том числе без JavaScript. Остальные работы открывают подробности; без JavaScript доступны сами изображения. Названия и изображения проектов представляют самостоятельные концепции, а не вымышленные клиентские заказы. Форма брифа сохраняет локальный TXT-файл и ничего не отправляет. Для приема заявок позже нужен настоящий контактный канал.

На главной шрифты локальные, лицензии в `assets/fonts/`. История сохраняет Google Fonts Caveat и локальный резервный Comfortaa. Новые WebP-изображения суммарно около 1,3 МБ; оригинальные личные фотографии в репозиторий не добавлены.

## Проверка

Синтаксис, сборка, ссылки под `/design/` и сохранность старого содержимого проверяются локально. Запуск Chromium в текущей среде завершается системным запретом, а подключенного браузера нет: визуальная проверка адаптивности и взаимодействий в браузере пока не выполнена.
