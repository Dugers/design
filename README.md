# Между строк

Первый визуальный прототип личной интерактивной истории. HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск

```sh
npm run dev
```

Открыть <http://localhost:5173>. Также можно просто открыть `index.html` в браузере.

## Редактирование

- `index.html` — вступление, записи, видимые и замаскированные даты. Названия и тексты пока демонстрационные.
- `style.css` — палитра, типографика, рисунки интерфейса, мобильная версия и раскрытие записей.
- `script.js` — закрытие предыдущей записи при открытии следующей. Без JavaScript записи тоже работают.
- `assets/night-sea.webp` — иллюстрация на странице; `night-sea.png` — её исходник.

Закрытые записи в этой версии статичны. Автоматического раскрытия по датам, админки, сохранения прогресса и серверной части пока нет. Реальные сюрпризы в содержимом страницы не раскрываются. Не добавляйте секретные тексты в HTML до момента публикации: маска даты не скрывает исходный код.

Рукописный шрифт Caveat подключён через Google Fonts; локальный Comfortaa служит резервным шрифтом. Перед автономным использованием стоит скачать Caveat в `assets/fonts` и подключить локально.

## Проверка прототипа

Проверены синтаксис JavaScript, локальные пути к ресурсам, ссылки на SVG-символы, точный текст вступления и логика закрытия предыдущей заметки. Дизайн-детектор не обнаружил замечаний.

В среде разработки запуск локального сервера и браузера запрещён (`EPERM`), поэтому адаптивная вёрстка и взаимодействия в реальном браузере пока визуально не проверены. Сам прототип не требует сервера: его можно открыть как локальный файл.
