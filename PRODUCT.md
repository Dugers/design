# 22:18 and Между строк

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript. No runtime dependencies or framework. A small Node build copies public files to dist for GitHub Pages.

## Users
The homepage is a design studio portfolio for visitors discovering 22:18. Katya can find a personal story through one illustrated portfolio artwork and use the personal daily action journal at /design/todo/. Anton maintains these surfaces.

## Product Purpose
A convincing independent studio portfolio at /design/, with a preserved interactive personal story at /design/story/. The studio page must stand on its own without romantic hints, riddles or secret labels.

## Capabilities and Constraints
- Five self-initiated portfolio concepts with generated high-quality project imagery. Do not invent client commissions, awards, commercial results or contact details.
- Portfolio category filters; four project descriptions; one illustrated artwork linking directly to story/.
- Studio and service information, native expandable services, and a downloadable local project brief. No message sending backend is configured.
- Two separate visual systems. Scope new studio styles to studio.css; preserve style.css and script.js for the story.
- All public URLs are relative so both directory routes work below the GitHub Pages /design/ base.
- The story retains its original opening, mystery, expandable notes and hand-drawn dark identity. User-authorized historical additions and future date masks extend its original content. The date 04.10.2026 is the first in-person meeting and must remain.
- Authorized story chapters: first online messages 25.09, first meeting 04.10, argument 08.10, reconciliation 09.10, first kiss and mutual declaration 10.10. The cause of the argument remains private.
- Future masks: warmth 23.10.2026; darkness xx.11.2026; unnamed icon-free locked chapter 0x.11.2026; map-legend finale hint xx.11.2026; continuation xx.xx.xxxx. The finale remains open to any real-world scenario and personal response.
- Original personal reference photographs must not enter public assets or the deployment.
- A separate /todo/ route is a personal action journal with localStorage persistence, a day-by-day history, timestamped door and pill actions, one-off checkboxes, and daily checkbox or repeated actions. Archiving actions preserves recorded history. It defaults to Krasnoyarsk time and offers timezone selection, including device time. Journal data stays in the current browser.
- Story remains a static prototype: no automatic timed unlock, administration, persistence or server.

## Brand Commitments
Studio: contemporary editorial minimalism, expressive 22:18 typography, asymmetric unboxed work grid, quality imagery, readable text and restrained motion. No overt romantic or puzzle language.
Story: dark, minimalist, visibly hand-drawn, personal and mysterious. Its existing design documentation lives in story/DESIGN.md.
The illustrated project preserves only broad hairstyles and silhouette/height differences from the supplied photographs. Faces are abstract and not copied.

## Evidence on Hand
User brief, original project files and two supplied couple photographs. The original story snapshot is preserved in git and /tmp/2218-original during implementation. Studio assets are generated specifically for the site; prompts are recorded in assets/studio/README.md.

## Open Decisions
Real studio contact channel, future story content and scheduling, and eventual production backend. No personal surprise details should be published ahead of time.
